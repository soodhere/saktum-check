# Security policy

Trust Check reads untrusted input by design: tool names, descriptions, schemas and responses from servers it tests. If you find a way for a tested server to affect the machine running Trust Check, its terminal, its reports or its signatures, please report it privately.

- Email: security@saktum.dev (until the domain is live, open a GitHub security advisory on this repository).
- Please include the version, the command you ran and a minimal server that reproduces the issue.
- We acknowledge reports within 3 working days and credit reporters in release notes unless asked not to.
