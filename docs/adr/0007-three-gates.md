# 0007 Own the three gates
**Decision:** Saktum is built to sit in the critical path of three gates: the build gate (Saktum Check as a required CI check), the buy gate (trust passport replacing vendor questionnaires) and the run gate (gateway decision and receipt on every call), linked by standards-traced evidence.
**Why:** must-have tools sit where work cannot proceed without them. Scanners touch the build gate, identity vendors and cloud gateways the run gate; nobody owns the buy gate for agent tools.
**Consequences:** every Saktum Check feature must make the CI gate easier to adopt or its evidence more useful for the passport.
